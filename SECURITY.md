# Security Policy

## Supported Versions

Only the latest release receives security fixes, both on
[crates.io](https://crates.io/crates/grelsolar) and on
[Docker Hub](https://hub.docker.com/r/grelinfo/grelsolar).

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately through
[GitHub Security Advisories](https://github.com/grelinfo/grelsolar/security/advisories/new).

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce it
- The affected version

You will receive an answer within 7 days. If the vulnerability is confirmed,
a fix is released as soon as possible and credited to you unless you prefer
otherwise.
